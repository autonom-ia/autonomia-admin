## Decisão

Hard-disable do workflow GitHub, remoção do default `prod` e do script genérico.
Esta PR é uma fase parcial (`Refs #8`) e não cria uma release nova nem encerra
a Issue: a reativação deve provar banco AppSell
isolado, migrations aditivas, staging, artifact por SHA, smoke e rollback.
O package local usa `DATABASE_URL` dummy e stage `ci`, sem ler SSM produtivo.

## Restrições

Nenhum deploy, secret, AWS, Environment, RDS compartilhado ou dado de cliente.
Foi criado somente o database Postgres local isolado `autonomia_admin_local`,
onde migrations Admin-only e testes foram executados. Não fazer merge.
