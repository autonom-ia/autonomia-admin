## Decisões

- Situação: o repositório não possuía Agent Harness.
  - Decisão: instalar em PR separada `#5`, sem misturar governança com código de produto.
- Situação: a migration 008 referenciava `financial.catalog_items` em banco Admin isolado.
  - Decisão: tornar somente o trecho Financial um no-op quando a tabela não existir, preservando o comportamento no RDS compartilhado.
- Situação: o primeiro hardening ainda criava qualquer principal Cognito válido como `autonomia_master` e `admin`.
  - Decisão: resolver apenas usuários ativos previamente provisionados; o login pode vincular `sub`, mas não cria acesso administrativo.
- Situação: o caminho Financial real da migration 008 não era exercitado pelo banco Admin isolado.
  - Decisão: adicionar fixture Financial local protegida contra banco não-test e cobrir rename, colisão por operador e idempotência.
- Situação: variáveis do banco de teste poderiam alcançar o passo Serverless no workflow de deploy.
  - Decisão: restringir `DATABASE_URL` e `DATABASE_SSL_MODE=disable` aos passos de migrate/test.
